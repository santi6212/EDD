# Conti Corleone Management System

Este proyecto es un prototipo jerárquico diseñado en C++ para gestionar la línea de sucesión de una familia de la mafia italiana utilizando estructuras de **Árboles Binarios**. 

El sistema procesa la información de los miembros de la familia a través de persistencia pura en archivos de texto, garantizando la inmutabilidad de las jerarquías de mando y aplicando reglas automáticas de sucesión ante eventos de fuerza mayor.

## Estructura del Proyecto

El repositorio cumple estrictamente con el formato de organización requerido:
*   `src/`: Contiene el código fuente del proyecto (`casanostra.cpp`).
*   `bin/`: Contiene el archivo de datos estructurado (`datos.csv`) y el ejecutable generado por el compilador.

## Requisitos

*   **Lenguaje:** C++11 o superior.
*   **Entorno:** Dev-C++
*   **Restricciones de Código:** 100% libre del uso de vectores (`std::vector`), manejado puramente mediante punteros nativos y memoria dinámica.
